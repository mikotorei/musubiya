# 結び屋（musubiya）

作り手みこのホームページ。みこが作ったゲームと道具の置き場です。

- 公開先：https://musubiya-miko.com/ （GitHub Pages）
- 作り：HTML と CSS だけの静的サイト（ビルド不要）

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | ホーム |
| `assets/css/style.css` | 見た目 |
| `CNAME` | 独自ドメインの設定 |
| `.nojekyll` | GitHub Pages の Jekyll 処理を止める |
| `CLAUDE.md` | 作業の決まりごと |
| `journal/` | 作業日誌 |
